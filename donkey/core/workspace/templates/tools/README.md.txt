# tools/ —— 工具开发约定

本目录存放本工作区可用的工具。当前阶段**不生成**任何内置工具文件 —— 内置工具由后续阶段生成（3 个内置 `@tool`：文件系统 / 命令行 / 网络抓取，以及工具包的初始化文件）。

## 开发约定

- **命名**：工具文件名用小写下划线（如 `web_fetch`），函数名用动宾短语（如 `fetch_page`）。
- **参数**：用类型注解声明全部参数与返回值；可选参数必须有默认值。
- **错误处理**：捕获可恢复的异常并返回结构化的错误信息，不得把调用堆栈直接抛给用户。
- **超时**：每次外部调用都必须设定超时（建议 30 ~ 60 秒），超时后给出明确的错误信息而不是无限等待。

## 与 Skill 的关系

工具属于 Skill 的第三层资源 —— Skill 的正文只描述"何时用哪个工具"，工具的具体实现落在本目录。
