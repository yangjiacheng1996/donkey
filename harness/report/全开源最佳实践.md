# LangGraph 全开源最佳实践（内网部署，不依赖 LangSmith）

> 适用场景：智能体完全运行在公司内网，无外网；不允许使用 LangSmith（含其 Studio UI、Tracing、Deployment、Hub 等所有云服务）。
> 目标：用 LangGraph + LangChain 全开源栈构建可观测、可持久化、可测试、可演进的智能体，并显著使用 Middleware 能力。

---

## 0. 核心原则

1. **永远不设置** `LANGSMITH_TRACING=true` / `LANGSMITH_API_KEY=...`。只要这两个变量未设置或显式 `false`，LangChain/LangGraph 不会把任何数据上传到 `api.smith.langchain.com`（见 `LangChain_doc/observability.md`、`LangGraph_doc/observability.md`）。
2. **永远不要用** LangSmith Studio UI（`smith.langchain.com/studio/?baseUrl=...`）。该 UI 强制跳转 LangSmith，需要 LangSmith API Key（见 `LangGraph_doc/studio.md`、`LangGraph_doc/local-server.md`）。
3. **永远不要用** LangSmith Deployment / LangSmith Cloud。把 `langgraph dev` 仅当作纯本地 in-memory 服务器（`http://127.0.0.1:2024`），生产用自己用 Docker / K8s 起 `langgraph-api` 服务（见下文 §10）。
4. **观测与调试通过自有手段**实现：`stream_mode` 事件流 + 自定义 Middleware + 标准 OpenTelemetry/Logging 即可覆盖 99% 场景。
5. **LLM 自托管或内网代理**：使用 `langchain.chat_models.init_chat_model(...)` 配 `base_url` / `api_key` 指向内网 OpenAI 兼容服务（如 vLLM、TGI、Ollama、Xinference、自研网关；见 `LangChain_doc/install.md` 与 `harness/demo/create_an_agent.py` 模板）。

## 4. 持久化（Checkpointers）—— 内网可选存储

文档：`LangGraph_doc/checkpointers.md`。LangGraph 内置 **5 个**独立开源 checkpointer 库，全部可在内网自托管：

| 库 | 适用场景 |
|---|---|
| `InMemorySaver`（`langgraph-checkpoint` 默认） | 开发、测试；不持久化，进程退出即失 |
| `SqliteSaver` / `AsyncSqliteSaver` | 单机/小规模生产；本地文件，可挂载 NAS |
| `PostgresSaver` / `AsyncPostgresSaver` | 生产首选，支持 async、加密、横向扩展 |
| `MongoDBSaver` | 公司已用 Mongo 的场景 |
| `CosmosDBSaver`（`langchain-azure-cosmosdb`） | Azure 内网部署 |

```python
# src/my_agent/checkpointer.py
from langgraph.checkpoint.postgres import PostgresSaver

def make_checkpointer():
    with PostgresSaver.from_conn_string(
        "postgresql://user:pwd@postgres.internal:5432/agent"
    ) as cp:
        cp.setup()  # 自动建表
        return cp

agent = create_agent(
    model=llm,
    tools=tools,
    checkpointer=make_checkpointer(),  # 见 §7：HITL/记忆必备
)
```

**加密**：设置 `LANGGRAPH_AES_KEY` 环境变量（pycryptodome AES），任何 checkpointer 都自动加密落盘（见 `LangGraph_doc/checkpointers.md` §Encryption）。

## 5. 可观测性方案（替代 LangSmith Tracing）

**LangSmith 之外的「同款能力」组合**：

### 5.1 流式事件（替代 Studio 实时面板）

```python
# stream_mode 覆盖 LangSmith 的可视化能力
for event in agent.stream(
    {"messages": [...]},
    config={"configurable": {"thread_id": t}},
    stream_mode=["values", "messages", "updates", "custom"],
    version="v2",
):
    # event 是 StreamPart dict: {"type": ..., "data": ...}
    # values: 全量 state；messages: token 流；updates: 增量；custom: 业务信号
    log_event(event)
```

文档：`LangGraph_doc/streaming.md`、`LangChain_doc/streaming.md`。

### 5.2 结构化审计日志（替代 trace 持久化）

用标准 `logging` + JSON Formatter 落到 ELK / Loki / 自研日志服务：

```python
# deploy/logging.json
{"version": 1, "formatters": {"json": {...}}, "handlers": {"file": {"class": "logging.FileHandler", "filename": "/var/log/agent/audit.jsonl"}}}
```

把 LangChain 的 debug 开关打开即可看到 graph runtime 的全部事件（model/tool/state 流转）：

```python
from langchain_core.globals import set_debug

set_debug(True)   # 之后 agent.invoke() / agent.stream() 输出 DEBUG 级 trace
```

或通过环境变量：

```bash
export LANGCHAIN_DEBUG=true
```

### 5.3 OpenTelemetry（可选）

LangChain / LangGraph 走 LangSmith `LangChainTracer`（见 `LangGraph_doc/observability.md:114-125`），它默认把数据上传到 LangSmith；**内网禁用 LangSmith 时不能用它**。要接入公司内 OTel Collector，需要：

1. **自定义 callback handler**：实现 LangChain `BaseTracer` 或 `CallbackHandler` 接口，把事件转成 OTel span，发到公司内 `OTLPSpanExporter`：
   ```python
   from langchain_core.callbacks import BaseCallbackHandler
   from opentelemetry import trace
   from opentelemetry.exporter.otlp.proto.grpc.trace_exporter import OTLPSpanExporter
   # ... 自行实现映射逻辑
   ```

2. **第三方包**：`langchain-otel-tracer`（社区维护，**非 LangChain 官方**）可作为桥梁，把 LangChain callback 转成 OTel span。

3. **stream 事件自收集**（推荐）：用 §5.1 的 `agent.stream(..., stream_mode=...)`，把 events 落到标准日志 / 消息队列，自行统计指标。`streaming.md` 内的 events 语义最完整，且与 LangSmith 无关。

> **不要**直接用 `langchain_core.tracers.langchain.LangChainTracer` 走内网 OTel —— 它默认走 LangSmith，需额外改造才能改 endpoint。

## 6. Middleware —— 核心能力（重点章节）

> 文档：`LangChain_doc/middleware/overview.md`、`built-in.md`、`custom.md`。
> 中间件不是独立 runtime，hook 直接运行在 `create_agent` 返回的 LangGraph 图里。可以把整套「中间件 + Agent」作为子图嵌入更大的 `StateGraph`。
>
> Hook 类型：
> - **Node-style**：`before_agent` / `before_model` / `after_model` / `after_agent`（按顺序或反向顺序执行，用于日志、校验、状态改写）。
> - **Wrap-style**：`wrap_model_call` / `wrap_tool_call`（嵌套执行，用于重试、降级、缓存、转换）。
> - **专用**：`@dynamic_prompt` 生成动态 system prompt。
>
> 执行顺序规则：`before_*` 顺序；`after_*` 倒序；`wrap_*` 嵌套。

### 6.1 推荐组合顺序（生产内网模板）

```python
from langchain.agents import create_agent
from langchain.agents.middleware import (
    SummarizationMiddleware,
    ModelRetryMiddleware,
    ToolRetryMiddleware,
    ToolErrorMiddleware,
    ModelCallLimitMiddleware,
    ToolCallLimitMiddleware,
    PIIMiddleware,
    HumanInTheLoopMiddleware,
    TodoListMiddleware,
)
from langgraph.checkpoint.postgres import PostgresSaver

agent = create_agent(
    model=llm,
    tools=tools,
    system_prompt=AGENT_SYSTEM_PROMPT,
    checkpointer=PostgresSaver.from_conn_string(DB_URI),

    middleware=[
        # 1. 上下文压缩（长对话省 token）
        SummarizationMiddleware(
            model=summary_llm,                  # 可用更便宜的内部模型
            trigger=("tokens", 6000),
            keep=("messages", 20),
        ),

        # 2. PII 防护（输入/输出都过一遍，敏感数据不出网）
        PIIMiddleware("email",      strategy="redact", apply_to_input=True, apply_to_output=True),
        PIIMiddleware("credit_card", strategy="mask",   apply_to_input=True),
        PIIMiddleware("id_card",    strategy="redact", detector=re.compile(r"\d{17}[\dXx]"),
                      apply_to_input=True, apply_to_output=True),

        # 3. 模型层重试 + 降级（容灾）
        ModelRetryMiddleware(max_retries=3, backoff_factor=2.0),
        ModelFallbackMiddleware("Qwen2.5-32B-Instruct"),  # 备用模型

        # 4. 调用限制（成本/防失控）
        ModelCallLimitMiddleware(thread_limit=50, run_limit=15, exit_behavior="end"),
        ToolCallLimitMiddleware(thread_limit=100, run_limit=20),
        ToolCallLimitMiddleware(tool_name="query_db", thread_limit=10, exit_behavior="error"),

        # 5. 工具错误格式化（不让原始异常泄露内部信息）
        ToolErrorMiddleware(
            on_error=lambda exc, req: (
                f"工具 {req.tool_call['name']} 失败：{type(exc).__name__}"
                if isinstance(exc, ValueError) else None
            )
        ),
        ToolRetryMiddleware(max_retries=2, backoff_factor=2.0, on_failure="continue"),

        # 6. 任务规划（复杂多步任务）
        TodoListMiddleware(),

        # 7. 高危工具的人工审批（HITL）
        HumanInTheLoopMiddleware(
            interrupt_on={
                "send_email":     {"allowed_decisions": ["approve", "edit", "reject"]},
                "delete_record":  {"allowed_decisions": ["approve", "reject"]},
                "read_data":      False,                      # 只读不需要审批
            },
        ),

        # 8. 自定义中间件：审计 / 计量 / 动态 prompt（见 §6.3）
        AuditMiddleware(),
        TokenUsageMiddleware(),
        DynamicSystemPromptMiddleware(),
    ],
)
```

### 6.3 自定义中间件模式（来自 `LangChain_doc/middleware/custom.md`）

#### 6.3.1 装饰器风格（推荐简单场景）

```python
# src/my_agent/middleware/audit.py
import json, logging, time
from typing import Any
from langchain.agents.middleware import before_agent, after_agent, AgentState
from langgraph.runtime import Runtime
from typing_extensions import NotRequired

audit_log = logging.getLogger("agent.audit")

# 自定义 state schema：声明 audit_id 字段（中间件不能直接 mutate 内置 AgentState）
class AuditState(AgentState):
    audit_id: NotRequired[str]

@before_agent(state_schema=AuditState)
def audit_start(state: AuditState, runtime: Runtime) -> dict[str, Any] | None:
    audit_id = f"run-{int(time.time()*1000)}"
    audit_log.info(json.dumps({
        "event": "agent_start", "audit_id": audit_id,
        "user_id": runtime.context.get("user_id") if runtime.context else None,
        "msg_count": len(state["messages"]),
    }, ensure_ascii=False))
    # 必须 return dict 以触发 state 更新（AgentState 本身不可变；返回值走 reducer）
    return {"audit_id": audit_id}

@after_agent(state_schema=AuditState)
def audit_end(state: AuditState, runtime: Runtime) -> dict[str, Any] | None:
    audit_log.info(json.dumps({
        "event": "agent_end", "audit_id": state.get("audit_id"),
        "final_tokens": state.get("cumulative_usage", {}),
    }, ensure_ascii=False))
    return None
```

> **要点**：
> 1. `AgentState` 不允许 `state["__audit_id"] = ...` 直接赋值——这是只读 TypedDict；要新增字段必须先 `class MyState(AgentState): ...: NotRequired[...]`，并用 `@hook(state_schema=MyState)` 声明。
> 2. node-style hook 必须 `return dict | None`，`None` 表示不更新 state。
> 3. 详见 `LangChain_doc/middleware/custom.md:170-186, 459-491` 的 `TrackingState` 模式。

#### 6.3.2 类风格（多 hook + 状态扩展）

```python
# src/my_agent/middleware/token_counter.py
from typing import Any, Callable
from langchain.agents.middleware import (
    AgentMiddleware, AgentState, ModelRequest, ModelResponse,
    ExtendedModelResponse,
)
from langgraph.runtime import Runtime
from langgraph.types import Command
from typing_extensions import NotRequired
import logging

log = logging.getLogger("agent.tokens")

class TokenUsageState(AgentState):
    cumulative_usage: NotRequired[dict]   # 自定义字段

class TokenUsageMiddleware(AgentMiddleware[TokenUsageState]):
    state_schema = TokenUsageState

    def wrap_model_call(
        self,
        request: ModelRequest,
        handler: Callable[[ModelRequest], ModelResponse],
    ) -> ExtendedModelResponse:
        resp = handler(request)
        usage = (resp.usage_metadata or {}) if hasattr(resp, "usage_metadata") else {}
        log.info("model_call tokens=%s", usage)
        return ExtendedModelResponse(
            model_response=resp,
            command=Command(update={"cumulative_usage": usage}),
        )
```

#### 6.3.3 动态 system prompt 注入（内网知识库 / 租户上下文）

```python
from collections.abc import Callable
from langchain.agents.middleware import (
    AgentMiddleware, ModelRequest, ModelResponse,
)
from langchain.messages import SystemMessage

class TenantContextMiddleware(AgentMiddleware):
    def wrap_model_call(self, request, handler):
        ctx = request.runtime.context or {}
        kb_block = ctx.get("kb_snippet", "")
        tenant = ctx.get("tenant_id", "default")

        new_blocks = list(request.system_message.content_blocks) + [
            {"type": "text", "text": f"\n[租户: {tenant}]\n{kb_block}"},
        ]
        return handler(request.override(
            system_message=SystemMessage(content=new_blocks)
        ))
```

#### 6.3.4 工具监控 / 包装

```python
from langchain.agents.middleware import wrap_tool_call, AgentMiddleware
from langchain.tools.tool_node import ToolCallRequest
from langchain.messages import ToolMessage
from langgraph.types import Command
from typing import Callable
import logging, time

log = logging.getLogger("agent.tools")

@wrap_tool_call
def audit_tool(request: ToolCallRequest, handler):
    t0 = time.time()
    log.info("tool_call name=%s args=%s", request.tool_call["name"], request.tool_call["args"])
    try:
        result = handler(request)
        log.info("tool_ok name=%s cost=%.3fs", request.tool_call["name"], time.time()-t0)
        return result
    except Exception as e:
        log.warning("tool_fail name=%s err=%s", request.tool_call["name"], e)
        raise
```

#### 6.3.5 `jump_to` 提前终止（护栏/限流场景）

```python
from langchain.agents.middleware import after_model, AgentState
from langchain.messages import AIMessage
from langgraph.runtime import Runtime
from typing import Any

@after_model(can_jump_to=["end"])
def block_sensitive(state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
    last = state["messages"][-1]
    if "BLOCK_KEYWORD" in str(last.content):
        return {"messages": [AIMessage("无法响应违规请求。")], "jump_to": "end"}
    return None
```

> 多个 wrap 中间件可返回 `ExtendedModelResponse` + `Command(update=...)` 合并状态：messages 用加法 reducer，普通字段「外层覆盖内层」（见 `LangChain_doc/middleware/custom.md` §Composition）。

## 7. 人在回路（HITL）—— 不需要 LangSmith

文档：`LangChain_doc/middleware/built-in.md` §Human-in-the-loop。

```python
from langchain.agents.middleware import HumanInTheLoopMiddleware
from langgraph.checkpoint.postgres import PostgresSaver

agent = create_agent(
    model=llm, tools=tools,
    checkpointer=PostgresSaver.from_conn_string(DB_URI),  # 必填
    middleware=[
        HumanInTheLoopMiddleware(
            interrupt_on={"send_email": {"allowed_decisions": ["approve", "edit", "reject"]}},
        ),
    ],
)

# 运行后从 interrupt 恢复
config = {"configurable": {"thread_id": "u-001"}}
result = agent.invoke({"messages": [HumanMessage("发邮件给 a@b.com")]}, config=config)
# result 含 __interrupt__，前端用 SDK 决策并 resend，无需 LangSmith
```

`@tool` 装饰的函数名 = 工具名 = 中间件 key。LangGraph 的 `interrupt` 机制把状态存入 checkpointer，跨进程恢复（见 `LangGraph_doc/interrupts.md`）。

## 8. Memory（短期 + 长期）

- **短期记忆**：直接用 `checkpointer`，`thread_id` 即会话 ID（`LangGraph_doc/add-memory.md`）。
- **长期记忆**：用 `langgraph.store.postgres.PostgresStore`（或 `InMemoryStore`），按 namespace 存储用户偏好/事实，跨会话检索（见 `LangGraph_doc/stores.md`）。

```python
from langgraph.store.postgres import PostgresStore
store = PostgresStore.from_conn_string(DB_URI)
store.setup()
agent = create_agent(
    model=llm, tools=tools, store=store, checkpointer=cp,
    middleware=[SummarizationMiddleware(model=llm, trigger=("tokens", 6000))],
)
```

## 9. 多 Agent 模式（全部开源）

`LangChain_doc/multi-agent/index.md` 给出 4 种范式：

| 范式 | 适用 | 实现 |
|---|---|---|
| **Subagents** | 任务可并行/委派 | 主 Agent 通过工具调用子 Agent |
| **Handoffs** | 状态机式切换 | 工具返回 `Command(goto=...)` 切换节点 |
| **Router** | 输入分类后分流 | `StateGraph` + 分类节点 + `add_conditional_edges` |
| **Skills** | 大型 prompt/工具按需加载 | 子图工具 + `LLMToolSelectorMiddleware` |

```python
# Router 示例：LangGraph 原生写法，不依赖 LangSmith
from langgraph.graph import StateGraph, START, END
class RouterState(TypedDict): messages: list; next_agent: str

builder = StateGraph(RouterState)
builder.add_node("classify", classify_node)
builder.add_node("support_agent", support_agent)
builder.add_node("billing_agent", billing_agent)
builder.add_conditional_edges("classify", lambda s: s["next_agent"])
builder.add_edge(START, "classify")
graph = builder.compile(checkpointer=cp)
```

### 10.2 生产部署：自托管 LangGraph API（Docker）

`langgraph dev` 是 in-memory 模式，不能用于生产。用 `langgraph-api` 容器：

```yaml
# deploy/docker-compose.yml
services:
  postgres:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: ${INTERNAL_PG_PASS}
    volumes: [pgdata:/var/lib/postgresql/data]

  agent-api:
    build: ..
    command: langgraph up --host 0.0.0.0 --port 8123
    environment:
      - LLM_BASE_URL
      - LLM_API_KEY
      - POSTGRES_URI=postgresql://postgres:${INTERNAL_PG_PASS}@postgres:5432/agent
    depends_on: [postgres]
    ports: ["8123:8123"]

volumes: {pgdata: {}}
```

`deploy/langgraph.json`：
```json
{
  "dependencies": ["."],
  "graphs": { "agent": "./src/my_agent/agent.py:agent" },
  "env": "./.env"
}
```

这样得到完全在内网、自托管、可水平扩展、无任何 LangSmith 调用的 Agent Server。

## 12. 常见错误与排查

| 报错（`harness/.../errors/*.md`） | 原因 | 处置 |
|---|---|---|
| `MISSING_CHECKPOINTER` | HITL / 限流中间件需要 checkpointer | `checkpointer=InMemorySaver()` |
| `INVALID_TOOL_RESULTS` | `AIMessage.tool_calls` 与 `ToolMessage` 不匹配 | 检查工具返回，确认 `tool_call_id` 一致 |
| `MODEL_AUTHENTICATION` | `LANGSMITH_API_KEY` 被设成空字符串触发探测 | 删 `LANGSMITH_*` 环境变量 |
| `GRAPH_RECURSION_LIMIT` | Agent 进入死循环 | 用 `ModelCallLimitMiddleware` / `ToolCallLimitMiddleware` |
| `INVALID_CHAT_HISTORY` | 消息历史被破坏 | 用 checkpointer 持久化 messages，禁止手工篡改 |

## 13. 端到端最小可运行模板

```python
# src/my_agent/agent.py
import os
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.tools import tool
from langchain.agents.middleware import (
    PIIMiddleware, SummarizationMiddleware, ModelRetryMiddleware,
    HumanInTheLoopMiddleware, TodoListMiddleware,
)
from langgraph.checkpoint.postgres import PostgresSaver

@tool
def query_db(sql: str) -> str:
    """查询内网数据库（只读）。"""
    # ... 内部 JDBC / SQLAlchemy ...
    return "..."

llm = init_chat_model(
    "Qwen2.5-72B-Instruct",
    model_provider="openai",
    base_url=os.environ["LLM_BASE_URL"],
    api_key=os.environ["LLM_API_KEY"],
)

cp = PostgresSaver.from_conn_string(os.environ["POSTGRES_URI"])
cp.setup()

agent = create_agent(
    model=llm,
    tools=[query_db],
    system_prompt="你是公司内网智能助手。",
    checkpointer=cp,
    middleware=[
        PIIMiddleware("email", strategy="redact", apply_to_input=True, apply_to_output=True),
        SummarizationMiddleware(model=llm, trigger=("tokens", 6000), keep=("messages", 20)),
        ModelRetryMiddleware(max_retries=3),
        TodoListMiddleware(),
        HumanInTheLoopMiddleware(interrupt_on={"query_db": {"allowed_decisions": ["approve", "reject"]}}),
        # 自定义中间件（见 §6.3）
        AuditMiddleware(), TokenUsageMiddleware(),
    ],
)

if __name__ == "__main__":
    out = agent.invoke(
        {"messages": [{"role": "user", "content": "查询 Q3 销售额"}]},
        config={"configurable": {"thread_id": "demo-1"}},
    )
    print(out["messages"][-1].content)
```
